# project_xboxsales_dashbord
Dashboard de vendas de assinaturas Xbox desenvolvido no Microsoft Excel, utilizando tabelas dinâmicas e visualização de dados para analisar indicadores de vendas e apresentar informações de forma organizada, clara e visualmente harmoniosa.
# 🎮 Dashboard de Assinaturas Xbox

## 📌 Sobre o projeto

Projeto desenvolvido no Microsoft Excel para organizar e analisar dados de assinaturas do Xbox Game Pass por meio de tabelas dinâmicas e de um dashboard visual.

A proposta é transformar uma base de dados em informações mais fáceis de consultar e interpretar, destacando indicadores relacionados aos planos, à renovação automática e à contratação de conteúdos adicionais.

## 🎯 Objetivos

- Organizar e estruturar uma base de dados;
- Praticar a criação e a utilização de tabelas dinâmicas;
- Interpretar dados para responder a perguntas de negócio;
- Apresentar informações de forma clara e visual;
- Desenvolver um dashboard com harmonia visual, cores e elementos organizados.

## 🗂️ Estrutura do arquivo

O projeto está dividido em quatro abas:

### `Assets`

Reúne elementos visuais de apoio, como a paleta de cores e recursos gráficos utilizados na apresentação do dashboard.

### `Bases`

Contém a base de dados das assinaturas, com informações como plano, data de início, renovação automática, preço da assinatura e contratação de conteúdos adicionais, como EA Play e Minecraft.

### `Cálculos`

Apresenta tabelas dinâmicas e resultados usados para responder a perguntas de negócio, incluindo:

- Faturamento de planos anuais, considerando a renovação automática;
- Vendas de assinaturas do EA Play;
- Valores relacionados ao Minecraft Season Pass.

### `Dashboard`

Reúne a apresentação visual dos dados e dos principais resultados, facilitando a leitura e a interpretação das informações.

## 🛠️ Ferramentas e recursos praticados

- **Microsoft Excel**
- Tabelas dinâmicas;
- Organização e estruturação de dados;
- Interpretação de dados e perguntas de negócio;
- Escolha e aplicação de cores;
- Harmonia visual e hierarquia das informações;
- Construção e apresentação de dashboard.

## 🧠 Principais aprendizados

O foco deste projeto foi aprender a transformar dados organizados em uma apresentação visual útil. Durante o desenvolvimento, pratiquei:

- Estruturar informações para facilitar a análise;
- Resumir dados com tabelas dinâmicas;
- Relacionar os resultados às perguntas de negócio;
- Escolher cores e organizar elementos para melhorar a leitura;
- Apresentar informações de forma objetiva em um dashboard.

A criação de dashboards é útil em atividades administrativas e de negócios, pois ajuda a resumir informações, acompanhar indicadores e apoiar a interpretação de resultados.
